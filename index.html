Frequently Asked Questions

Everything you need to know about integrating ReClaire into your stack.

How does ReClaire handle dynamic JavaScript heavy web pages? +
ReClaire uses an adaptive double-pass engine. It first attempts high-speed HTTP retrieval. If dynamic JS rendering is detected or required, it seamlessly falls back to a headless Chromium Playwright instance with network-idle waiting.
What happens if an extraction fails schema validation? +
We utilize native structured generation schemas directly on Gemini 2.5 Flash. The output is guaranteed to align with your provided JSON model or Pydantic definition.
How does the 5-URL batch intelligence limit benefit my integration? +
By aggregating 5 URLs concurrently into a single LLM context window pass, ReClaire reduces your execution cost to just 3 tokens while saving you from hitting 15 RPM free-tier LLM rate limits.
Are unused tokens rolled over each month? +
Free tier token balances refresh automatically on a 30-day cycle. Additional tokens earned via referral milestones or testing claims remain in your account until used.
